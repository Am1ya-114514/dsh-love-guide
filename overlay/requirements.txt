#   python -m venv .venv
#   .venv\Scripts\python -m pip install -r overlay/requirements.txt --ignore-requires-python
#
# 关于 --ignore-requires-python：
#   rapidocr-onnxruntime 在 PyPI 上把 Requires-Python 写成 >=3.6,<3.13，但它是
#   纯 Python 包 + onnxruntime，实测在 Python 3.13 上跑得很好（本机 3.13.12 +
#   rapidocr 1.2.3，聊天正文识别置信度 0.91~0.94）。不加这个参数 pip 会直接拒绝，
#   报一堆 "Ignored the following versions that require a different python version"。
#   不想用这个参数就用 Python 3.12 建虚拟环境——那是上游声明的支持范围。
#
# win_io.py / chat_reader.py / service.py 是悬浮窗的全部后端代码：
